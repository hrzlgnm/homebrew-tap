# hrzlgnm's Homebrew Tap

This repository contains Homebrew casks for hrzlgnm's applications.

## Installation

Tap this repository:
```bash
brew tap hrzlgnm/tap
```

## Available Casks

### mdns-browser
Browse mDNS services on your network.

```bash
brew install --cask mdns-browser
```

Or install directly without tapping:
```bash
brew install --cask hrzlgnm/tap/mdns-browser
```
